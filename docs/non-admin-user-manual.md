# UPSI2u Non-Admin User Manual

## 1. Purpose
This manual explains how to use UPSI2u as a non-admin user.

Target users:
- Student (buyer, and can become seller/helper)
- Helper (seller mode)
- Community user (buyer, with verification flow)

---

## 2. Before You Start
Make sure you have:
- An active account
- Access to your email inbox (for verification)
- A phone with WhatsApp (for direct communication with buyer/seller)
- Basic profile details ready (name, phone, photo)

---

## 3. Account Access

### 3.1 Register
1. Open Sign up.
2. Fill in required details.
3. Submit registration.

### 3.2 Login
1. Open Log in.
2. Enter email and password.
3. Submit to access dashboard.

### 3.3 Forgot Password
1. Open Forgot Password.
2. Enter your registered email.
3. Follow reset link from your email.

### 3.4 Email Verification (Required)
If your email is not verified, the system will ask you to verify before normal usage.

---

## 4. Main Navigation (Non-Admin)

When in buyer view, top menu includes:
- Home
- Find Services
- About Us
- Help
- Rewards (logged-in users)
- Notifications
- Favorites
- Orders
- Your Profile

If you are an eligible helper in seller mode, menu changes to:
- Dashboard
- My Services
- Incoming Orders
- Points
- Your Profile

---

## 5. Buyer Guide (Requesting Services)

### 5.1 Find Services
1. Open Find Services.
2. Use:
- Category list on left
- Search box
- Sort (Recommended/Newest/Price)
- Availability filter
3. Open a service card to view details.

### 5.2 Review Service Details
On service details page, check:
- Service description
- Package and pricing
- Seller profile summary
- Reviews
- Availability status

### 5.3 Place an Order Request
1. Choose package (Basic/Standard/Premium if available).
2. Select date.
3. Select time (for time-slot services).
4. Add message or notes (optional).
5. Submit request.

Important rules:
- You cannot create duplicate active requests to the same helper/service.
- For session-based services, overlapping slots are blocked.

### 5.4 Track Orders
Open Orders. Requests are organized by tabs:
- Pending
- In Progress
- Completed

Common statuses:
- pending: waiting for seller response
- accepted: seller accepted
- in_progress: seller started work
- waiting_payment: seller marked work complete, waiting buyer payment
- disputed: issue reported, pending resolution
- completed: order finished
- rejected/cancelled: order closed

### 5.5 Buyer Actions by Status
- Pending:
  - Cancel Request
  - View Details
- In progress / Waiting payment:
  - Contact seller via WhatsApp
  - Report issue if needed
- Waiting payment:
  - Upload payment proof (JPG/PNG/PDF, max 1MB)
- Completed:
  - Leave review (if not reviewed yet)

### 5.6 Dispute Flow (Buyer)
If there is a problem:
1. Open the relevant order.
2. Report the issue with reason.
3. Status becomes disputed.
4. If you are the reporter, you can withdraw report before final resolution.

## 6. Favorites

### 6.1 Save a Service
- Use the favorite toggle on a service.

### 6.2 View Favorites
1. Open Favorites from navigation.
2. Browse your saved services.
3. Open service detail from list.

---

## 7. Notifications

### 7.1 View Notifications
1. Open Notifications (bell icon).
2. Review latest activity.

### 7.2 Mark Notifications
- Mark individual notification as read
- Or use Mark all as read

Typical notifications include:
- New service requests
- Request status updates (accepted/rejected/etc.)
- Admin warnings

---

## 8. Buyer Rewards and Leaderboard

### 8.1 Rewards Dashboard
Open Rewards to view:
- Current buyer points
- Recently earned points
- Available rewards
- Your recent redemptions

### 8.2 Redeem Reward
1. Choose a reward card.
2. Click redeem.
3. System generates redemption code.
4. Points are deducted from buyer points.

### 8.3 Buyer History and Leaderboard
- Buyer History: full points transactions
- Leaderboard: view buyer and seller rankings (view-only for some roles)

---

## 9. Student to Seller (Helper) Onboarding

Use Become a Seller from the menu.

### 9.1 Eligibility Rules
You must meet student status requirements:
- Active student status
- At least 3 months before graduation

### 9.2 Verification Steps
Complete all steps:
1. Verify location (must be within Muallim District)
2. Upload profile photo
3. Complete live selfie check

After success:
- Your role is converted to helper
- Seller mode is enabled
- You are redirected to complete seller profile

---

## 10. Seller Profile Setup
After verification, complete seller profile:
- Faculty
- Course
- Bio
- Skills
- Work experience note
- Work experience file (optional, allowed formats include PDF/DOC/DOCX/TXT/JPG/PNG, max 1MB)

Then continue to create your first service.

---

## 11. Seller Guide (Providing Services)

### 11.1 Switch Mode
Eligible helpers can toggle:
- Switch to Selling
- Switch to Buying

### 11.2 Seller Dashboard
Seller dashboard shows:
- Performance summaries
- Quick actions
- Trend range (weekly/monthly/yearly)

### 11.3 Create New Service
Open My Services > Create New Service.

Form steps:
1. Overview
- Service Title
- Category
- Cover Image (optional)

2. Pricing
- Basic package (required)
- Optional Standard/Premium packages
- Duration, billing unit, included items

3. Description
- Full service explanation

4. Availability
- Time Slots or One-off Task mode
- Session duration (for slot-based services)
- Weekly schedule
- Block dates

Submit with Publish Service Now.

### 11.4 Manage Services
Open My Services to:
- View all services
- Filter by category/search
- Edit service
- Delete/archive service
- Check approval status (pending/approved/rejected)

### 11.5 Set Availability
Seller availability can be updated by:
- Toggling available/unavailable
- Defining unavailable date range

System updates service status accordingly.

---

## 12. Incoming Orders (Seller Mode)

Open Incoming Orders. Tabs:
- Pending
- In Progress
- Completed

### 12.1 Pending
Actions:
- Accept Request
- Reject (reason required)
- View Full Details
- Contact requester via WhatsApp

### 12.2 In Progress
Typical sequence:
1. accepted -> click Start Work
2. in_progress -> click Finish Work
3. waiting_payment -> review proof and finalize

### 12.3 Payment Verification
If buyer uploads proof:
- Click Check Proof
- Finalize as paid when confirmed

If needed, seller can mark paid manually.

### 12.4 Seller Dispute
During in_progress or waiting_payment:
- Report issue
- Status becomes disputed

If you are the reporter, you can withdraw dispute before final outcome.

---

## 13. Seller Points and Certificate

Open Points (seller mode) to view:
- Total seller points
- Recent points
- Certificate achievement progress

Rules:
- Seller points are awarded when orders are completed
- Buyer also earns points on completed order
- Certificate achievement can be unlocked once requirement is met

You can also open:
- Points History
- Leaderboard
- Certificate page (if unlocked)

---

## 14. Community User Verification
Community users must complete verification before full action access.

Verification steps:
1. Verify location in Muallim District
2. Upload profile photo
3. Complete live selfie check
4. Upload proof document (PDF/JPG/PNG, max 1MB)

After submission:
- Status becomes pending review
- Wait for admin approval
- You will be informed after review

---

## 15. Profile and Security
Open Your Profile to manage:
- Profile details (name, phone, photo, etc.)
- Password and security
- My Reviews section

Notes:
- Some account types may have restricted email editing.
- Save changes with Save Profile.

---

## 16. Account Restrictions and What They Mean

You may see access restrictions based on account status.

Common outcomes:
- Seller blocked: cannot use seller features, can still use buyer features
- Suspended or blacklisted: account access is restricted and may force logout
- Community unverified: prompted to complete community verification before normal actions

Always follow the in-app message shown for your account state.

---

## 17. Troubleshooting

### 17.1 Cannot become seller
Check:
- Student status is active
- Graduation is not within 3 months
- All verification steps completed

### 17.2 Cannot submit community verification
Check:
- File type is PDF/JPG/PNG
- File size is under 1MB
- Location verification completed first

### 17.3 Cannot create or update service
Check:
- Required fields are filled (title, category, basic package, description)
- Image size <= 1MB
- You are in active helper status

### 17.4 Cannot proceed in order flow
Check current order status and allowed actions:
- pending: accept/reject/cancel
- accepted: start work
- in_progress: finish work or report issue
- waiting_payment: verify payment / finalize
